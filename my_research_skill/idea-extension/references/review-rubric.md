# Review Rubric — 多视角审核与打分

只评 problem 和 method 这个 idea 本身，不评论文措辞或章节结构。

## 多专家视角（绝不单评审）

每个 idea 至少用四个独立视角各留独立笔记，视角之间要真的不同：

- **Field expert（领域专家）**：这个问题对领域重要吗？受众是谁？赌注多大？是不是真瓶颈？
- **Method expert（方法专家）**：机制讲清楚了吗？假设成立吗？有没有更简单的设计达到同样效果？
- **Experiment expert（实验专家）**：最小实验跑得出来吗？baseline 公平吗？什么结果能证伪它？信号会被噪声淹没吗？
- **Hostile prior-art reviewer（敌意审稿人）**：第一刀砍哪？"这不就是 X 加个 trick 吗"怎么防？新颖性会在哪篇近邻工作下坍塌？

## 10 维打分（1-5，加权）

| 维度 | 权重 |
| --- | ---: |
| 问题重要性 | 12 |
| 相对近邻工作的新颖性 | 14 |
| 概念创新 | 12 |
| 方法可靠性 | 14 |
| 优雅 / 简洁 | 8 |
| 资源下的可行性 | 8 |
| 实验说服力 | 10 |
| 受众 / 场景契合 | 8 |
| 时机 / 热度 | 6 |
| 风险调整后的潜力 | 8 |

权重和为 100。不适用维度标 N/A 并说明。

### 分数锚点

- **5**：清晰的顶会信号。问题重要，机制可辩护，新颖性强或值得一查，证据包可信。
- **4**：有潜力。有真贡献 + 可修复的缺口，需补新颖性接地 / 方法细节 / 证据设计。
- **3**：边缘。大改后可能可发，但当前问题-方法链有重要疑点。
- **2**：弱。增量小、动机不足、接地差或难验证，可能要转向。
- **1**：idea 阶段致命。问题对场景不重要，新颖性大概率坍塌，方法不可靠，或核心 claim 无法验证。

## 致命门（fatal gate）

命中任一，总分封顶在 2，且必须显式标出：

- 新颖性在某篇大概率存在的近邻工作下坍塌。
- 问题对目标场景太窄。
- 方法是换了名字的旧 trick。
- 核心 claim 用现有资源无法验证。
- 证据需要一个时间内造不出的数据集 / 证明 / 系统。
- idea 依赖审稿人会拒绝的隐藏假设。

## 报告规则

- **新颖性状态**与分数解耦：`searched` / `partially-known` / `user-provided-only` / `needs-literature-search`。把"低新颖"和"未知新颖"分开报。
- **confidence 与 score 分开报**。
- 最终推荐之一：`accept-to-develop` / `revise` / `pivot` / `abandon` / `needs-literature-search`。
- 多 idea 时按"扣除致命风险后"的潜力排序，不按平均分；优先致命新颖性/可靠性/证据风险更少的，即使它没那么时髦。
