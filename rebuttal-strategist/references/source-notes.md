# Source Notes

Use these sources as design background, not as mandatory citations in every rebuttal.

## Rebuttal Guidance

- ACL Rolling Review in-cycle author response: responses should focus on clear factual errors or serious misunderstandings; the primary route remains revision/resubmission, and in-cycle responses should not include new experimental results requested by reviewers.  
  https://aclrollingreview.org/in-cycle-author-response/

- AAAI-26 author rebuttal FAQ: responses should focus on the substance of reviews, especially factually incorrect claims; avoid focusing on tone or fairness; new rushed experiments should not be central.  
  https://aaai.org/conference/aaai/aaai-26/aaai-26-faq-for-authors-rebuttal/

- NeurIPS reviewer guidelines: author response is part of the review process and should help reviewers update their assessment through clarification and actionable answers.  
  https://neurips.cc/Conferences/2025/ReviewerGuidelines

- IJCAI 2026 author response FAQ: author responses are for pressing reviewer questions, factual errors, and serious review concerns, not for starting an open-ended dialogue.  
  https://2026.ijcai.org/authors-reponse-faq/

## GitHub / Skill Design References

- OpenAI skills repository: skills are reusable folders of instructions, scripts, and resources; current docs point to Codex skill/plugin guidance.  
  https://github.com/openai/skills

- OpenAI Codex skills docs: use skills to package reusable instructions and resources.  
  https://developers.openai.com/codex/skills

- Agent Skills open standard: background on skill folders and discoverable task capabilities.  
  https://agentskills.io/

- One-page rebuttal template repository: useful as evidence that compact academic response templates often prioritize constrained layout and concise comment-response structure.  
  https://github.com/Estrellajer/one-page-rebuttal-template

- CV rebuttal template repository: groups responses by reviewer, which is useful when reviewers raise distinct concerns with many small questions.  
  https://github.com/guanyingc/cv_rebuttal_template

- ACM multimedia rebuttal template repository: illustrates a compact conference-style response format for strict space budgets.  
  https://github.com/gulucaptain/acmmm_rebuttal_template

- Journal review response template repository: illustrates the more exhaustive comment/response/revision structure used in revision letters.  
  https://github.com/klb2/review-response-template

## Related Research Often Useful For Rebuttals About Agents

- SWE-bench: repository-level software tasks require multi-file coordination and realistic debugging, useful when arguing that model capacity matters.  
  https://arxiv.org/abs/2310.06770

- SWE-agent: agent-computer interfaces affect automated software engineering behavior, useful when arguing that scaffold/harness design matters.  
  https://arxiv.org/abs/2405.15793

- Lost in the Middle: long-context models can fail to use information reliably across long inputs, useful for long-tail requirement discussions.  
  https://aclanthology.org/2024.tacl-1.9/
