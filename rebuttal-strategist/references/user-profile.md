# User Profile For Rebuttal Work

Confidence: medium. These are based on explicit user instructions during ReproAgent rebuttal work and should be updated only with user approval.

## Confirmed Preferences

- Start by understanding each reviewer's intent and decision risk.
- Set an explicit goal, then subgoals, before doing substantial rebuttal work.
- Use agent-team investigation for complex reviewer concerns when the user asks for depth.
- Mine real paper evidence, experiment results, logs, generated repositories, and released artifacts before drafting claims.
- Prefer paper tables, figures, appendix text, and official/open-source artifacts in final reviewer-facing responses.
- Keep internal evidence paths in working memos; avoid local filesystem paths in final rebuttal text.
- Write each reviewer response separately when reviews have distinct concerns.
- Use concise, polite, structured responses: thank the reviewer, acknowledge valid points, answer each weakness, and state camera-ready changes.
- Avoid defensive writing, over-apology, and broad self-undermining limitations.
- Be direct about real limitations, but frame them as scope, evidence boundaries, or future work.

## Common Bottlenecks To Guard Against

- Drafts can become too shallow if they summarize concerns without mining concrete cases.
- Drafts can become too messy if detailed code evidence is pasted directly into final author response.
- Strong claims need paper-table or artifact evidence before being used in rebuttal.
- The final response should not look like a code audit report; detailed audits belong in appendix/camera-ready plans or internal notes.

## Default Collaboration Style

- Work like a senior paper revision collaborator.
- Challenge weak reasoning directly and propose a repair path.
- Use Chinese for internal strategy when the user writes in Chinese.
- Use the venue's expected language and style for final rebuttal drafts, usually concise academic English.
- Do not ask for clarification when the path is clear from paper/review artifacts; make a reasonable assumption and proceed.
